Set up Meijia audio in Anki
  1. In Anki’s Manage Note Types, clone the note type used by your lesson cards and name it “Mandarin Meijia”. Keep Front and Back, then add a field named Chinese.
  2. For existing cards, select only your lesson deck’s notes in Browse and use Change Note Type to switch to Mandarin Meijia. Map Front to Front and Back to Back, and retain the existing card template mapping to preserve scheduling.
  3. Export these words and import the CSV into your lesson deck using Mandarin Meijia. Map columns 1–3 to Front, Back, Chinese. Choose to update existing notes matched by the first field, rather than import duplicates. Check the import preview before continuing.
  4. In Cards, add this below {% templatetag openvariable %}Front{% templatetag closevariable %} in the front template:
{% templatetag openvariable %}tts zh_TW voices=Apple_Meijia:Chinese{% templatetag closevariable %}

Anki provides the play button. With the standard back template, it also appears after revealing the answer. If it is hidden, enable audio play buttons in Anki’s preferences. Autoplay follows your existing deck settings.

Meijia must be installed on the device where you review. If it does not play, temporarily add {% templatetag openvariable %}tts-voices:{% templatetag closevariable %} to the template to check the available voice names. Chinese contains only traditional characters, so the simplified form is not read a second time.
